mdi-weather-windy Airmar 300WX WeatherStation Setup

This extension connects to an Airmar 300WX WeatherStation via NMEA 0183 serial, reads wind, heading, atmosphere, and GPS data, and streams it to BlueOS and Cockpit.

1 Wire the Sensor to a USB-to-RS232 Adapter

The Airmar 300WX has four wires. You need a USB-to-RS232 serial adapter and access to the BlueBoat fuse board for power.

Power
Airmar 300WX Wire Destination Red (Power +) → Fuse board V1 (battery voltage) screw terminal channel. Install an appropriately rated MINI blade fuse. Black (Ground) → Snap-wire splice → Battery Ground and adapter Black (see below) The 300WX requires 9–40 V DC. On a BlueBoat with 4S batteries, the V1 rail provides ~12–16.8 V. See the BlueBoat Integration Guide — Connecting to Power for fuse board details.
Data (NMEA 0183)
Airmar 300WX Wire USB-to-RS232 Adapter Wire Yellow (TX+) → White (RX) on adapter White (TX−) → Yellow (TX) on adapter Ground: Use a snap-wire splice connector to join three wires at the ground point — the Airmar black wire, the adapter black wire, and a wire to battery ground. A shared ground reference is essential for a clean signal.

Plug the USB end of the adapter into the vehicle computer (Raspberry Pi, Navigator, etc.) and proceed to step 2.

2 Connect in the Extension
  1. In the Connection panel above, click the refresh button and select the serial port from the dropdown (or pick it from Device Identification).
  2. Click Connect. The extension will auto-negotiate 115200 baud for maximum bandwidth.
  3. Once connected, the Dashboard tab shows live sensor data.
Tip: The extension remembers the last port and reconnects automatically on restart. 3 Display Data in Cockpit

The extension streams wind, GPS, and heading data to Cockpit's data-lake over WebSocket. To set it up:

  1. In Cockpit, open Menu > Settings > General.
  2. Scroll to Generic WebSocket connections.
  3. Add the URL: ws://{{ connectionInfo.connected ? 'vehicle-address' : 'vehicle-address' }}:8765
  4. Click the + button to save the connection.

Once connected, the following variables appear in Cockpit's data-lake:

Variable Description wind-direction-true Wind direction relative to north (degrees) wind-speed-kts Wind speed (knots) heading-true True heading from compass (degrees) gps-latitude GPS latitude (decimal degrees) gps-longitude GPS longitude (decimal degrees) gps-altitude-m GPS altitude (metres) gps-satellites Number of GPS satellites in use gps-fix-quality GPS fix quality (0=none, 1=GPS, 2=DGPS) gps-course-true Course over ground (degrees true) gps-speed-kts Speed over ground (knots)

All variables are streamed regardless of the ArduPilot UDP mode. They can be assigned to any Cockpit widget, mini-widget, or HUD overlay.

4 Build a Custom Wind Widget Coming soon — Instructions for building a DIY Cockpit widget that graphs live wind speed and direction from the WeatherStation data-lake variables. 5 Configure NMEA Sentences

Use the Sentences tab to enable or disable individual NMEA sentence types and adjust their transmission rates. The bandwidth indicator shows how much serial capacity is in use at the current baud rate.

mdi-speedometer-slow Serial baud rate (advanced)

If the link is at 115200 baud but you need standard 4800 NMEA (for example for another listener), you can command the WeatherStation to 4800 baud and reopen the port. This also saves 4800 as the device default (same as a manual baud change).

mdi-numeric Force device to 4800 baud

Current link is already at {{ connectionInfo.baud_rate }} baud — forcing 4800 is only offered at 115200.

Connect to the WeatherStation above to use this option.

mdi-help-circle-outline Troubleshooting
  • No serial port listed? Check that the USB cable is connected and the adapter driver is loaded. Click the refresh button to rescan.
  • Garbled data? The extension auto-switches to 115200 baud. If the device was left in a mixed state, power-cycle the WeatherStation and reconnect.
  • Cockpit not showing wind data? Verify the WebSocket URL is correct and that the extension is connected to the WeatherStation (green status above).
  • Need to stay at 4800 baud? Check the "Stay at 4800 baud only" box before connecting, or after connecting at 115200 use Setup → Serial baud rate (advanced) to force the device to 4800 baud.
